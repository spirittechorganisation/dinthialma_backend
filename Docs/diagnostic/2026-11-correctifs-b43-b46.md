Requête de contrôle de la productionFichier : `Docs/diagnostic/controle-b43.sql`. Elle est **en lecture seule** (SELECT uniquement), à lancer dans pgAdmin. Je ne l'ai exécutée sur aucun serveur.- **Requête 1** : écarts par membre pour chaque tontine événementielle déjà distribuée. Colonnes : tontine, membre, statut, supprimé le, total VALIDE, mise distribuée, net distribué, `montant_non_distribue`.- **Requête 2** : tontines événementielles terminées **sans aucune** distribution enregistrée mais avec des cotisations VALIDE. Elle donne soit une distribution vide à cause du bug (tous les cotisants étaient non actifs), soit un faux positif (distribution antérieure à V034).- **Requête 3** : synthèse par tontine (total encaissé, total distribué, écart).Limite : une cotisation EN_RETARD validée **après** la distribution finale (possible avant ce correctif, `validateCotisation` ne bloquant pas) apparaît aussi comme écart. C'est un vrai montant non distribué, mais pour une autre cause.```sql-- Requête 1 (extrait ; texte complet dans controle-b43.sql)WITH tontines_distribuees AS (    SELECT DISTINCT d.tontine_id FROM dinthialma.distributions_evenementielles d    WHERE d.deleted_at IS NULL),valide_par_membre AS (    SELECT c.tontine_id, c.membre_id, SUM(c.montant) AS total_valide    FROM dinthialma.cotisations c    JOIN tontines_distribuees td ON td.tontine_id = c.tontine_id    WHERE c.deleted_at IS NULL AND c.statut = 'VALIDE'    GROUP BY c.tontine_id, c.membre_id),distribue_par_membre AS (    SELECT d.tontine_id, d.membre_id, SUM(d.montant_cotise) AS total_distribue,           SUM(d.montant_net) AS net_distribue    FROM dinthialma.distributions_evenementielles d    WHERE d.deleted_at IS NULL    GROUP BY d.tontine_id, d.membre_id)SELECT t.id AS tontine_id, t.nom AS tontine, t.statut AS statut_tontine,       m.id AS membre_id, u.first_name || ' ' || u.last_name AS membre, u.phone AS telephone,       m.statut AS statut_membre, m.deleted_at AS membre_supprime_le,       COALESCE(v.total_valide, 0) AS total_cotisations_valide,       COALESCE(dp.total_distribue, 0) AS mise_distribuee,       COALESCE(dp.net_distribue, 0) AS net_distribue,       COALESCE(v.total_valide, 0) - COALESCE(dp.total_distribue, 0) AS montant_non_distribueFROM valide_par_membre vFULL OUTER JOIN distribue_par_membre dp       ON dp.tontine_id = v.tontine_id AND dp.membre_id = v.membre_idJOIN dinthialma.tontines t        ON t.id = COALESCE(v.tontine_id, dp.tontine_id)JOIN dinthialma.tontine_membres m ON m.id = COALESCE(v.membre_id, dp.membre_id)JOIN dinthialma.users u           ON u.id = m.user_idWHERE t.tontine_type = 'EVENEMENTIELLE'  AND COALESCE(v.total_valide, 0) <> COALESCE(dp.total_distribue, 0)ORDER BY t.nom, montant_non_distribue DESC;```---## 5.
